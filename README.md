# AI-City-Survival-System
I have made an AI City survival engine which is a  prototype system that trains engineers before they work on real smart cities. 
NeoVerse is a C++ smart city management system developed.
The project simulates how a modern city manages important services such as electricity, transportation, healthcare and security. It includes features such as engineer login authentication, different clearance levels, event management, emergency handling, city data storage and analytics. Throughout the development of this project, I applied various object-oriented programming concepts, including classes, objects, inheritance, encapsulation and polymorphism. I also used data structures such as vectors, queues, stacks and lists, along with file handling and STL algorithms to organise, process and store information. The main goal of this project was to improve my C++ programming skills and demonstrate how different programming concepts can work together to create a functional city management system.
