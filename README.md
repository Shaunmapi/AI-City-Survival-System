# NeoVerse: AI City Survival System

The NeoVerse project is a C++ program that covers the main parts of the assignment. The project has one main file called `main.cpp`, which runs the different questions. The other files are `Engineer.h` for the login system, `CityDataManager.h` for storing sensor readings and city logs, `EventSystem.h` for events and emergencies, `CityArchitecture.h` for the different city systems, and `Analytics.h` for the STL algorithms. The program also creates files such as `engineers.dat`, `events.dat`, `city_logs.dat`, `config.txt` and `exported_city_logs.csv` for saving information.

To run the program, compile it using g++ with `g++ -std=c++17 main.cpp -o NeoVerse`. On Windows, you can use `g++ -std=c++17 main.cpp -o NeoVerse.exe` and then run it with `.\NeoVerse.exe`. The program uses a vector for sensor readings, a list for city logs, a queue for normal events and a stack for emergency events. It also uses STL functions such as `sort`, `find_if`, `min_element`, `max_element` and `count_if`.

The project also shows different C++ concepts such as classes, constructors, inheritance, encapsulation and polymorphism. The city systems include Power, Transport, Health and Security, which all use the main `CityComponent` class. The program can save and load engineers, events and city logs using files, as well as export the city logs to a CSV file. The files are separated into header files to keep the project organised, while `main.cpp` is used as the main entry point. The written assignment requirements such as Times New Roman size 12, 1.5 spacing, Harvard referencing and the signed declaration apply to the assignment document, not the C++ project files.
